# Карточка П10 — свой агент Hamlet

**Кто читает:** ревизор и инженер.
**Решение:** в том, что видит модель и владелец, нет имени muse и Meta; агент зовётся Hamlet (слово владельца 27.11).
**Нормально:** устройство и смысл текстов — прежние, меняются только имена; ссылки «откуда взято» в комментариях кода, `docs/` и коммитах остаются.
**Как обманет:** замена вслепую, ломающая смысл («Muse app» → «Hamlet app», которого нет); пропущенное имя в тексте, собираемом из ядра; тексты в `prompts/`, отличные от muse не только именем.

Ветка `e/P10-hamlet`.

1. Пространство инструментов `muse.*` → `hamlet.*`: `read`, `write`, `edit`, `exec`, `skill_search`, `connector_search` (и всё, что уже есть). Описания — те же тексты ядра, в них `muse.` → `hamlet.`.
2. Тексты, которые видит модель (описания инструментов, `prompts/compaction/`, `prompts/subagent/`): «Muse» → «Hamlet»; где текст говорит о приложении muse, службах Meta, тарифах — фразу убрать, а не переименовать. Каждую такую правку перечислить в коммите (файл → было → стало).
3. Файлы в `prompts/` больше не байт в байт с muse: рядом — `prompts/SOURCES.md`, где для каждого файла записан исходник в muse-live и список правок (это рабочий документ, его модель не видит).
4. Имена в коде (крейты, типы, константы), где стоит `muse`, — на нейтральные или `hamlet`.
5. Тест: ни один текст, который уходит модели (описания всех инструментов, все `prompts/`), не содержит `muse`, `Muse`, `Meta` — проверка по всему реестру и папке; на подмене (одно слово вернуть) красный.
6. Все прежние тесты зелёные на обоих поставщиках.

**Сдача:** sha ревизору.
