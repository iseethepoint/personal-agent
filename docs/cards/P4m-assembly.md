# Карточка П4м — сборка агента Hamlet

**Кто читает:** ревизор и инженер.
**Решение:** крейты (`model`, `loop`, `tools`, `memory`, `cron`, `goals`, `browser`) собираются в одного агента: одна программа `hamlet`, одна папка настроек. До сих пор каждый крейт проверялся сам по себе, главный агент инструментов целиком не получал.
**Нормально:** как у muse — один движок поднимает реестр моделей, все инструменты, память, службы расписаний и наблюдателей, браузер, подагентов и ящик; агент — это папка настроек (CLAUDE.md «Шаблон»: новая папка — новый агент, без копирования кода).
**Стоит на:** форма демона muse (`hatch-daemon-core`, `hatch-daemon-services`, `runtime/provider_config.rs` — `docs/coverage/core.md`); `docs/cards/P2…P4k`.
**Как обманет:** инструмент есть в крейте, но не попал в реестр главного агента; службы не стартуют; настройки зашиты в код.

Ветка `e/P4m-assembly`.

1. Крейт `agent/hamlet` (программа `hamlet`). Запуск: `hamlet --agent <папка>`; в папке агента — `config/models.toml`, `config/web.toml`, настройка базы (адрес Postgres, имя переменной), домашняя папка агента (`SOUL.md`, `USER.md`, `MEMORY.md`, `HEARTBEAT.md`…), путь к системным навыкам и коннекторам. Пример папки — `agents/hamlet/` в репозитории (без ключей).
2. Сборка главного агента: реестр моделей, все инструменты (`hamlet.read/write/edit/exec`, `process.*`, `browser.search/open/find/lookup_citation_url`, `browser.browse/windows`, `hamlet.memory_*`, `hamlet.skill_search`, `hamlet.connector_search`, `todo.write`, `subagent.*`, `cron.*`, `hooks.*`, `user_goal.*`, `tracking.*`, `forget.*`), секреты для скрытия (П4г), закреплённое начало подсказки (П3б), сжатие (П3в), ящик (итоги подагентов, расписаний, наблюдателей, окон браузера) — новый ход по приходу вести.
3. Службы: такт расписаний и наблюдателей, фоновая сверка памяти, монитор подагентов — стартуют с программой и останавливаются вместе с ней.
4. Вход для проверки — строки из stdin, ответ в stdout (это не П6: мессенджер и настоящий вход — там). Живых вызовов моделей нет без слова владельца.
5. Тесты: запуск с поддельными поставщиками (оба провода) и временной папкой агента: в одном разговоре — запись файла, поиск в памяти, заведение расписания, срабатывание расписания по подделанным часам и весть в ящик → новый ход; список инструментов главного агента совпадает с ожидаемым полным списком (тест-перечень, красный, если что-то не подключено); тест имён П10 — по реестру собранного агента.

**Сдача:** sha ревизору.
