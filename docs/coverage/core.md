## Оговорки

- Деление смешанных папок (`› имя`) сделано по именам файлов; полный перечень «файл → группа → пометка» — `coverage_core_files.tsv` в той же папке. У 3 файлов с одинаковыми именами в разных подпапках привязка к группе подобрана по совпадению пути, не вручную.
- «Сделано» ставилось, если главная часть группы есть в `agent/*/src`; недостающие мелочи названы в причине (например, `file_io` — нет перевода документов; `memory_flush` — нет периодического сброса; `turn_core` — нет очистки разговора).
- «В плане» для живого браузера опирается на строку П4 («…браузер…») и раздел «Дальше» карточки П4; отдельной карточки ещё нет.
